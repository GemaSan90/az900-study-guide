2. Cuadros maestros de la unidad

CUADRO IMPORTANTE PARA FUTURAS CERTIFICACIONES: Herramientas de Administración de Azure
  • GRÁFICA | Azure Portal: Consola basada en web para compilar, administrar y supervisar recursos en la nube[cite: 3].
  • ENTORNO | Cloud Shell: Shell basado en navegador con autenticación integrada. Sin instalación local[cite: 3].
  • LÍNEA DE COMANDOS | Azure PowerShell: Scripting basado en Cmdlets para tareas de automatización repetibles[cite: 3].
  • LÍNEA DE COMANDOS | Azure CLI: Comandos basados en Bash con las mismas capacidades que PowerShell[cite: 3].
  • ASISTIDO POR IA | Copilot in Azure: Asistente de IA para orientación contextual en lenguaje natural[cite: 3].
CUADRO IMPORTANTE PARA FUTURAS CERTIFICACIONES: Azure Arc — Gestión Unificada entre Entornos

Azure Arc (vía Azure Resource Manager)[cite: 3]:

  • └─ Azure: Recursos nativos administrados con directivas, supervisión y cumplimiento[cite: 3].
  • └─ On-premises (Local): Servidores, Clústeres Kubernetes, SQL Server, Servicios de datos, VMs[cite: 3].
  • └─ Other Clouds (Multinube): Servidores, Clústeres Kubernetes, SQL Server, Servicios de datos, VMs[cite: 3].

HERRAMIENTAS (Azure Portal, CLI/PowerShell, REST APIs/SDKs) ──> AZURE RESOURCE MANAGER (Auth + Orquestación) ──> SERVICIOS (Compute, Networking, Storage + Data)[cite: 3]

3. Conceptos clave

Azure Portal

Qué es: Consola unificada basada en web para administrar suscripciones y recursos mediante GUI[cite: 4].

ASIR: Equivalente al Administrador del Servidor (Server Manager) o consolas MMC web de Windows Server[cite: 4].

Sirve para:

  • Compilar, administrar y supervisar infraestructuras y apps[cite: 4].
  • Crear paneles personalizados para visualización de recursos[cite: 4].

Examen: Disponibilidad continua y presencia en cada centro de datos (tolerante a fallos)[cite: 4].

Ejemplo: Crear una Máquina Virtual desde un explorador web sin instalar software[cite: 4].

Azure Cloud Shell

Qué es: Entorno de comandos ejecutable en navegador, con autenticación automática[cite: 4].

ASIR: Acceso por SSH o PowerShell Remoto precargado desde una consola web sin cliente local[cite: 4].

Sirve para:

  • Ejecutar scripts de PowerShell o Bash sin instalar CLI/PowerShell localmente[cite: 4].
  • Acceso directo asociando un almacenamiento para guardar scripts[cite: 4].

Examen: Autentica automáticamente con las credenciales de la sesión activa de Azure[cite: 4].

Ejemplo: Administrar recursos desde un Chromebook o equipo cliente sin permisos de instalación[cite: 4].

Azure PowerShell vs Azure CLI

Qué es: Herramientas de línea de comandos multiplataforma (Windows, Linux, Mac) para automatización[cite: 4].

ASIR: PowerShell cmdlets habituales en Windows Server vs Scripts Bash en Linux[cite: 4].

Sirve para:

  • Automatizar la creación repetitiva de infraestructura[cite: 4].
  • Interactuar directamente con la API REST de Azure[cite: 4].

Examen: Son funcionalmente equivalentes; la elección depende de la preferencia sintáctica del administrador (Cmdlets vs Bash)[cite: 4].

Ejemplo: Crear 50 máquinas virtuales iterativamente con un script[cite: 4].

Azure Arc

Qué es: Servicio que extiende la gestión y gobernanza de ARM a servidores locales, Kubernetes y otras nubes[cite: 4].

ASIR: Proyectar servidores locales o de otros hipervisores dentro del inventario de Azure Active Directory / ARM[cite: 4].

Sirve para:

  • Aplicar Azure Policy e inventario unificado en entorno híbrido/multinube[cite: 4].
  • Gestionar servidores Windows/Linux y bases de datos fuera de Azure[cite: 5].

Examen: Proyecta recursos FUERA de Azure dentro de ARM[cite: 5].

Ejemplo: Controlar directivas de seguridad de un servidor físico local desde el Portal de Azure[cite: 5].

Infraestructura como Código (IaC) — ARM Templates & Bicep

Qué es: Gestión e implementación de infraestructura mediante archivos de definición declarativos[cite: 5].

ASIR: Despliegue automatizado de roles/servicios mediante scripts desatendidos o DSC[cite: 5].

Sirve para:

  • Despliegues repetibles, coherentes e idempotentes[cite: 5].
  • Definir orden de dependencias y ejecución en paralelo[cite: 5].

Examen: ARM usa sintaxis JSON; Bicep es un lenguaje declarativo más conciso y fácil de leer[cite: 5].

Ejemplo: Redefinir toda la red y servidores de la empresa en un único archivo .bicep[cite: 5].

6. Preguntas Learn (Examen)

¿Qué servicio le ayuda a administrar los entornos de Azure, locales y multinube?

Respuesta correcta: Azure Arc[cite: 6].

¿Por qué?: Azure Arc extiende el plano de control de Azure Resource Manager (ARM) a infraestructura ubicada fuera de Azure (On-premises y otras nubes)[cite: 6].

Trampa: Azure Policy o Azure Cloud Manager no gestionan la proyección de recursos de múltiples nubes por sí mismos[cite: 6].

¿Qué dos componentes podría usar para implementar una implementación de 'infraestructura como código'?

Respuesta correcta: Plantillas de Bicep y ARM[cite: 6].

¿Por qué?: Ambos son lenguajes declarativos diseñados para definir la infraestructura deseada e implementarla a través de ARM[cite: 6].

Trampa: Azure Policy y Azure Arc son para gobernanza y gestión híbrida, no formatos de definición de IaC[cite: 6].

8. Frases de examen

  • Azure Resource Manager (ARM) centraliza la autenticación, autorización y orquestación de todas las solicitudes[cite: 6].
  • Azure Arc gestiona servidores, clústeres de Kubernetes y bases de datos tanto en local como en otras nubes[cite: 7].
  • Cloud Shell permite ejecutar comandos desde el navegador web sin instalar herramientas en el equipo local[cite: 7].
  • Bicep ofrece una sintaxis más limpia y concisa que las plantillas JSON de ARM[cite: 7].
  • Copilot en Azure actúa como asistente operativo en lenguaje natural que requiere validación humana[cite: 7].

9. Trucos para memorizar

  • Azure Arc ──> El puente hacia servidores locales y otras nubes[cite: 7].
  • ARM ──> La puerta de entrada a todos los servicios de Azure[cite: 7].
  • Bicep ──> El hermano fácil y moderno de las plantillas JSON[cite: 7].
  • Cloud Shell ──> La terminal web sin instalación[cite: 7].
  • Copilot ──> El copiloto/asistente (el humano siempre confirma)[cite: 7].

10. Repaso exprés

  1. Todas las peticiones a Azure (Portal, CLI, PowerShell, API) pasan obligatoriamente por Azure Resource Manager (ARM)[cite: 7].
  2. Azure Portal es la interfaz gráfica Web accesible desde cualquier navegador[cite: 7].
  3. Cloud Shell es la terminal integrada en navegador que no requiere instalación local y autentica automáticamente[cite: 7].
  4. Azure CLI (basado en Bash) y Azure PowerShell (cmdlets) son funcionalmente equivalentes para scripting y automatización[cite: 7].
  5. Infraestructura como Código (IaC) permite definir el estado deseado en archivos reutilizables e idempotentes[cite: 7].
  6. Las Plantillas ARM estructuran la IaC mediante archivos JSON[cite: 7].
  7. Bicep es un lenguaje declarativo simplificado que compila en plantillas ARM[cite: 7].
  8. Azure Arc extiende la gobernanza y gestión de ARM a servidores locales (On-premises), Kubernetes y multinube (AWS/GCP)[cite: 7].
  9. Copilot en Azure ayuda a redactar scripts, consultas y arquitecturas usando IA contextual[cite: 7].
  10. La decisión final sobre cambios en producción generados por Copilot SIEMPRE recae en el administrador humano[cite: 7].
