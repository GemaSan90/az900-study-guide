TEMA 1/3

Herramientas de administración e interacción

Idea principal. Azure ofrece múltiples vías de acceso e interacción con los recursos, adaptándose tanto a la administración visual como a la automatización masiva.

Herramientas de Administración de AzureMúltiples interfaces sobre una misma API de ARM
Azure Portal
Consola web para compilar, administrar y supervisar recursos.
Cloud Shell
Terminal web con autenticación automática.
Azure PowerShell / CLI
Scripting imperativo y comandos multiplataforma.
Copilot in Azure
Asistente IA contextual para acelerar operaciones.
HerramientaPlataformaCaso de uso principal
Azure PortalWeb (Navegador)Gestión visual y supervisión puntual de recursos.
Cloud ShellNavegador webLínea de comandos rápida sin requerir instalación local.
Azure CLIMultiplataforma (Bash)Automatización y comandos basados en entornos Linux/Bash.
Azure PowerShellMultiplataforma (Cmdlets)Automatización avanzada integrada en entornos Microsoft.
Para el examen. Cloud Shell autentica de forma transparente utilizando las credenciales de tu sesión activa en el Portal de Azure.

Traducción ASIR

El Portal equivale al Server Manager o consolas MMC web; Cloud Shell es una sesión SSH/PowerShell directa en el navegador; CLI y PowerShell son tus scripts de automatización masiva (.sh o .ps1).

TEMA 2/3

Azure Arc

Idea principal. Azure Arc permite extender la gobernanza y el plano de control de Azure Resource Manager (ARM) hacia servidores, clústeres de Kubernetes y bases de datos situados fuera de Azure.

Azure Arcvía Azure Resource Manager (ARM)

Azure

  • Recursos nativos en la nube
  • Directivas y cumplimiento unificado

On-premises (Local)

  • Servidores físicos y virtuales
  • Clústeres Kubernetes y SQL Server

Otras Nubes (Multinube)

  • Instancias en AWS o GCP
  • Infraestructura heterogénea
Para el examen. Si el enunciado menciona la gestión de servidores locales o de otras nubes desde Azure, la respuesta correcta es siempre Azure Arc.

Traducción ASIR

Es instalar un agente de control en equipos físicos de tu propio CPD para que aparezcan en el panel central de la nube y reciban políticas corporativas como si estuvieran dentro.

TEMA 3/3

Infraestructura como Código (ARM y Bicep)

Idea principal. IaC sustituye la configuración manual por archivos declarativos de texto. Azure Resource Manager procesa estas plantillas para desplegar la infraestructura de forma automatizada, coherente e idempotente.

Plantillas ARM (JSON) | Bicep (DSL Declarativo)
▼
Azure Resource Manager (ARM)Orquestación y validación de dependencias
▼
ComputeNetworkingStorage + Data
CaracterísticaPlantillas ARMBicep
FormatoJSON estructuradoDSL (Lenguaje específico de dominio)
LegibilidadExtenso y complejoLimpio, conciso y fácil de leer
FuncionamientoNativo en AzureCompila automáticamente a JSON de ARM
Para el examen. Bicep simplifica enormemente la sintaxis de las plantillas ARM en JSON manteniendo la misma potencia de despliegue declarativo e idempotente.

Traducción ASIR

Equivale a los ficheros de despliegue desatendido (Unattended/DSC) donde declaras el estado final del sistema y dejas que el motor despliegue todo en orden.

PREGUNTAS DE LEARN

Comprobación de conocimientos

1. ¿Qué servicio le ayuda a administrar los entornos de Azure, locales y multinube?

✅ Respuesta: Azure Arc.

Razón: Extiende las capacidades de administración y directivas de ARM a infraestructuras externas.

2. ¿Qué dos componentes podría usar para implementar una implementación de "infraestructura como código"?

✅ Respuesta: Plantillas de Bicep y ARM.

Razón: Ambos lenguajes declarativos están diseñados específicamente para definir arquitecturas en Azure.

CIERRE

Repaso final (Flashcards)

  • ARM: Capa central que autentica, autoriza y orquesta cada llamada en Azure.
  • Cloud Shell: Consola web integrada y lista para usar sin instalaciones previas.
  • Azure Arc: Puente unificador para servidores locales y multinube.
  • Bicep: Sintaxis moderna y limpia para la Infraestructura como Código.
  • Copilot: Asistente inteligente de apoyo operativo (la decisión final es humana).
